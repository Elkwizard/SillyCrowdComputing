# Silly Crowd Computing
Welcome! This is a silly project I made to enumerate solutions to a random math problem I was unable to let go. We haven't found the answer yet, and you can join the search at [ihatethisproblem.org](https://ihatethisproblem.org)!

Warning: This website will use a lot of your CPU if you tell it to, so be careful about your battery life.

Disclaimer: This is *not* a cryptocurrency miner. You can check the source code, and see it's doing something far less useful (impressively).
